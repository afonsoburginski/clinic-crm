# clinic-crm

Villiére: painel de clínica em Next.js e API em Bun, Hono e PostgreSQL.

O frontend atualmente utiliza dados de demonstração no navegador. A API ainda exige integração e revisão das regras de domínio antes do uso com dados reais. Consulte `frontend/specs/` e `backend/README.md` para detalhes.

Para desenvolvimento, instale as dependências em `frontend/` e `backend/` com Bun e siga as instruções de configuração da API. Execute `bun run typecheck` e `bun run test` em cada serviço.
